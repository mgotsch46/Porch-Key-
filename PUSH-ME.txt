Troubleshooting
---------------
"git is not recognized as an internal or external command"
    Git isn't installed. https://git-scm.com/download/win
    Install with all defaults, close the terminal, open a new one, retry.

"Authentication failed" or it asks for a password
    Don't type your GitHub password — it won't work.
    Choose the browser sign-in option if offered. If it keeps failing,
    install Git for Windows (link above), which includes the credential
    manager that handles this properly.

"Updates were rejected"
    Run:  git push -u origin main --force
    (Safe — the repo was empty.)
