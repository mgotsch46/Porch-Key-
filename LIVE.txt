STILL TO CONNECT (whenever you're ready)
----------------------------------------
Stripe — card, bank transfer, Cash App Pay
    1. dashboard.stripe.com -> Developers -> API keys -> secret key
    2. Railway -> porchpay -> Variables -> add STRIPE_SECRET_KEY
    3. Stripe -> Webhooks -> Add endpoint:
       https://porchpay-production.up.railway.app/api/stripe/webhook
       event: checkout.session.completed
    4. Add the signing secret as STRIPE_WEBHOOK_SECRET
    5. Stripe -> Settings -> Payment methods -> enable Cash App Pay
       and ACH Direct Debit

PayNearMe — cash at Walmart / 7-Eleven / CVS
    Apply at paynearme.com. Once approved add PNM_API_KEY, PNM_SITE_ID
    and PNM_WEBHOOK_SECRET, and give them this callback URL:
       https://porchpay-production.up.railway.app/api/paynearme/webhook
    Until then cash codes work manually — the buyer generates a code,
    you mark it paid in the admin portal.

Anthropic — AI reading of closing docs and bank statements
    console.anthropic.com -> API key -> add as ANTHROPIC_API_KEY
